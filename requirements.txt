# Namestitev:  pip install -r requirements.txt
#
# Zakaj ">=" in ne "==" ?
#   Različice so navedene kot NAJNIŽJE še delujoče, ne kot točne.
#   Če jih pripnemo z "==", se namestitev na novejšem Pythonu podre:
#   pip za točno tisto različico ne najde pripravljenega paketa (wheel),
#   zato jo poskusi prevesti iz izvorne kode – za to pa potrebuje prevajalnik
#   in razvojne datoteke PostgreSQL (pg_config), ki jih na sistemu običajno ni.
#   S ">=" pip vedno vzame različico, ki za tvoj Python paket ima.
